# R&S Auto Rentals

Private car rental company website (daily/weekly rentals for gig drivers and local
renters) plus an internal CRM/ops backend.

**Start here: [`CLAUDE.md`](./CLAUDE.md)** — full project state, architecture, setup
instructions, and next steps.

Quick start for the website:

```bash
cd web
npm install
cp .env.example .env.local   # add Square credentials, see CLAUDE.md
npm run dev
```
